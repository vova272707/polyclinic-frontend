# Система регистрации студентов на медосмотр
Проект представляет собой систему для регистрации студентов на медицинский осмотр. Система включает в себя веб-сервис, веб-приложение и десктопное приложение, которые позволяют студентам записываться на медосмотр, а администраторам — управлять расписанием и данными.
